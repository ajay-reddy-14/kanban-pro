# Kanban Pro 🚀

A high-performance, interactive Kanban board built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**. This project showcases advanced frontend engineering concepts including complex state management and drag-and-drop orchestration.

![Kanban Pro Preview](https://via.placeholder.com/800x400?text=Kanban+Pro+Preview)

## ✨ Key Features

- **Fluid Drag & Drop**: Move tasks between columns and reorder them seamlessly using `@dnd-kit`.
- **Global State Management**: Powered by **Zustand** with persistent storage.
- **In-Place Editing**: Quick editing for task content and column titles.
- **Modern Glassmorphic UI**: A premium dark-themed interface with subtle animations and gradients.
- **Fully Responsive**: Designed to work across different screen sizes.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State**: [Zustand](https://github.com/pmndrs/zustand)
- **DND**: [@dnd-kit](https://dndkit.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or later

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/kanban_pro.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
